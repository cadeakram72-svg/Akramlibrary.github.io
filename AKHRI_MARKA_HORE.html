Naqshadda cusub ee ka dambaysa Welcome

Qaybta kore, hero-ga maktabadda iyo Welcome sidii hore ayay u yihiin. Qaybta hoose ayaa loo beddelay dukaan/maktabad casri ah oo cagaar iyo cream leh.

1. GitHub geli

  1. ZIP-ka ku samee Extract All.
  2. Fur folder-ka GITHUB_UPLOAD. Gudihiisa waxaa ku jira 11 fayl.
  3. GitHub ka fur repository-ga Akramlibrary.github.io.
  4. Dooro Add file → Upload files. Geli dhammaan 11-ka fayl ee folder-ka gudihiisa yaalla, isla meesha index.html hore u yaallay.
  5. Ha gelin folder-ka GITHUB_UPLOAD isagoo dhan, ZIP-ka, ama SOURCE_REACT.zip.
  6. Riix Commit changes. Magacyada hore waxay beddelayaan nuqulladii hore; inta kale way ku darsamayaan.
  7. Marka GitHub Actions deployment-ku dhammaado, website-ka ku fur Ctrl + Shift + R. Telefoonka ku tijaabi tab cusub.
Buugaagta iyo SQL-kii hore dib uma gelinaysid. Account-ka, owner dashboard-ka, akhriska PDF-ga iyo habka lacag-bixinta hore ayaa la sii adeegsanayaa.

2. Faallooyinka iyo liiska wararka fur

Tani waa hal tallaabo oo dheeraad ah. Website-ka iyo buugaagtu way shaqayn karaan ka hor intaadan tallaabadan samayn.

  1. Fur 04_REVIEWS_NEWSLETTER.sql adigoo adeegsanaya Notepad.
  2. Ctrl + A → Ctrl + C si aad u koobiyeyso qoraalka SQL-ka oo dhan.
  3. Supabase → mashruucaaga → SQL Editor → New query.
  4. Ku dheji qoraalka gudaha faylka. Ha ku dhejin magaca faylka oo keliya.
  5. Riix Run. Waxaa la filayaa Success. No rows returned.

SQL-kani wuxuu ku daraa kaydka faallooyinka iyo email-ka dadka ku biira. Ma beddelayo buugaagta, milkiilaha, qiimayaasha ama dalabyada. Email-yada wararka si otomaatig ah uma dirayo; adeeg email diris ah ayaa weli loo baahan yahay haddii aad rabto fariimo la diro.

3. Hubin kooban

  • Raadi Meditations; shaandhee Somali ama English.
  • Guji qalbiga buugga, kadib fur wishlist-ka.
  • Ku dar buug lacag leh dambiisha; fur dambiisha oo hubi magaca/qiimaha.
  • Buugga bilaashka ah fur; tijaabi Next iyo Previous.
  • Login kadib hubi My Profile; iibsashadii hore waxay ku jirtaa My purchases.
  • Haddii aad SQL-ka cusub gelisay, tijaabi faallo buug bilaash ah iyo isqorista email-ka. Faallo buug lacag ah waxaa qori kara akoon iibsaday.

Waxa si ula kac ah run looga dhigay

Buugaagta waa kuwa kaydkaaga ku jira. Lama samayn reviews, tiro macaamiil ama iib aan jirin. Maaddaama maktabaddu dhijitaal tahay, shipping iyo returns alaab jireed ah laguma ballanqaadayo. EVC/eDahab/SIM waxay adeegsadaan habkaaga hadda: maamulka ayaa lacagta xaqiijiya. Visa, Mastercard, PayPal iyo Apple Pay lama hawlgelin mana la sheegayo inay shaqaynayaan.

Hal akoon wuxuu u baahan yahay hal oggolaansho buug kasta. Dambiishu nuqullo badan oo isla buugga ah ma iibinayso. Lacagta buug kasta gooni ayaa loo xaqiijiyaa.

4. Koodhka iyo backup

SOURCE_REACT.zip waa React/TypeScript/Tailwind source-ka naqshadda cusub. Ku kaydi laptop-kaaga iyo meel backup ah. Looma baahna inaad GitHub Pages ku upload-garayso si website-ku u shaqeeyo. Haddii mustaqbalka naqshad la beddelayo, koodhkan sii qofka ama AI-ga kuu cusboonaysiinaya.

Haddii cusboonaysiintu dhib keento, dib ugu noqo commit-kii ka horreeyey GitHub. Ha tirtirin database-ka, users-ka ama buugaagta.

Ogow: cusboonaysiintan lama daabicin adiga beddelkaaga. 11-ka fayl waa inaad GitHub gelisaa. SQL-ka cusubna adiga ayaa Supabase ku ordiya.
