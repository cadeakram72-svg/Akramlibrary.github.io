3. Lacagta gacanta lagu xaqiijiyo

  1. Iibsaduhu akoonkiisa ha ku soo galo, buugga doorto, EVC/eDahab/SIM doorto.
  2. Batoonka keypad-ka wuxuu codsanayaa furitaanka telefoonka. Qaar ka mid ah telefoonada ma taageeraan USSD link; koodhka gacanta ayaa lagu qoraa. Koodhadhka waxaa la adeegsaday sida mulkiiluhu bixiyey; ku hubi shirkadda ka hor furitaanka dadweynaha.
  3. Macmiilku wuxuu hubiyaa magaca qaataha ABDIWAHID iyo qadarka, kadibna taleefankiisa ayuu ku xaqiijiyaa. Website-ka ha gelin PIN.
  4. Macmiilku wuxuu geliyaa Transaction ID ee rasiidka. Tani waa codsi hubin, mana aha caddeyn lacag la helay.
  5. Dashboard → Orders. Ku hubi diiwaanka EVC/eDahab: tixraaca, qadarka, qaataha, waqtiga iyo in aan hore loogu isticmaalin iib kale. Screenshot keliya ha ku ansixin.
  6. Haddii lacagtu timid, taabo Confirm received. Buugga ayaa si joogto ah ugu xirmaya akoonkaas. Haddii lacagtu aanay jirin ama tixraacu khaldan yahay, taabo Reject, una sheeg macmiilka sababta.
  7. Macmiilku ha furo My Profile → My purchases → Refresh → Read. Mar kale lacag ha looga qaadin. Dalab sugaya wuxuu xiraa batoonnada lacag-dirista.

Approve labo jeer la taabto ma abuuro iib labaad. Macmiilku naftiisa ma ansixin karo. Diiwaanka codsiga waxaa ku jira user ID; Supabase Authentication → Users ayaad kaga garan kartaa akoonka.

4. Waxa lacag-bixinta otomaatigga ahi u baahan tahay

EVC/WaafiPay, eDahab iyo kaar bangi wali API lacag-bixin toos ah kuma xirna xirmadan. Waxay u baahan yihiin:

  1. Akoon ganacsi oo adeeg-bixiyuhu ansixiyey iyo heshiiska/khidmadaha.
  2. API sandbox, merchant ID iyo credentials si ammaan ah server-ka loogu kaydiyo. Ha gelin Secret Key GitHub ama chat.
  3. Server xaqiijiya jawaabta lacagta; matching order ID, qadarka, currency iyo merchant; joojiya isku-celinta; kadib xaq akhris siiya.
  4. Kaar bangi: adeeg checkout martigeliya oo akoonkaaga taageera; website-kan laguma ururinayo card number ama CVV.
  5. Tijaabinta success, cancel, failure, pending, duplicate, refund iyo lacag dhab ah oo yar marka la oggolaado.

Dokumentiyada: WaafiPay · eDahab. Ilaa taas la helo, nidaamka shaqayn kara waa xaqiijinta gacanta ee kor ku sharaxan.

6. Backup iyo soo-celin

  1. Ka hor update kasta: GitHub Code → Download ZIP; ku keydi taariikh. Ku hay laptop iyo kayd kale oo adiga kuu gaar ah.
  2. Dashboard → Export data: wuxuu soo dejinayaa JSON buugaag, dalabyo iyo xuquuqda akhriska. Wuxuu ka kooban yahay xog macaamiil; ha dhigin repository public ah.
  3. PDF iyo covers: nuqullada asalka ah gooni u keydi; Supabase Storage ka soo dejiso nuqullada haddii aanad asalka haysan. Export data ma soo dejiyo PDF ama sawirro.
  4. Database: isticmaal backup/dump ku habboon qorshahaaga Supabase. Auth users, schema, policies iyo storage files waxay u baahan yihiin qorshe backup u gaar ah. Ha u qaadan JSON-ku inuu yahay backup buuxa.
  5. Khalad naqshadeed/code: dib u geli faylasha ZIP-kii ka horreeyey ama GitHub commit-kii saxda ahaa ku noqo. Ha tirtirin database-ka.
  6. Buug la qariyey/la saaray: Restore/Show ku soo celi. SQL-yada seed-ku dib uma soo celinayaan wax-ka-beddel tirtirmay; xogta backup-ka ayaa loo baahan yahay.
  7. Xog database oo luntay: jooji maamulka wax-qorista, keydi xogta hadda, ku soo celi backup tijaabo mashruuc kale marka hore, hubi user IDs/orders/entitlements, kadib u soo celi production. Ha samayn restore indho la’aan ah.

7. Mulkiilaha iyo wareejinta

Adiga ha lahaado akoonnada GitHub, Supabase iyo Google Cloud, recovery email iyo 2FA. Xirmadani waxay kaa dhigaysaa maamulaha iyadoo la adeegsanayo SQL Editor-ka mashruucaaga; ma wareejinayso akoon cid kale leedahay. Haddii aanad haysan akoonnadaas, wareejinta hay’adda mashruuca waa tallaabo gaar ah.

Wax-ka-beddel naqshadeed mustaqbalka: kaydi ZIP-kii ugu dambeeyey, soo dir faylasha cusub iyo waxa aad rabto. AI ama developer ayaa wax ka beddeli kara. Ma u baahnid inaad website-ka dib uga bilowdo eber.

Waxa xirmadani aanay ku jirin: app Play Store/App Store, API payment otomaatig ah, card checkout, cloud favorites/progress, restore otomaatig ah iyo notifications. Kuwaas si gooni ah ayaa loo qorsheynayaa.
