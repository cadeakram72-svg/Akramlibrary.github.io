# Akram Library
Free digital reading in English, Somali and Arabic.

## Upload / Gelinta GitHub
Extract the ZIP and open akram-upload-ready. Upload ALL files inside that folder directly to the repository root. Keep index.html alongside all assets-- files. Do not upload the ZIP itself or an enclosing folder.

All asset filenames are flat to make browser uploading simpler. Existing old assets folders may remain; this version uses the assets-- filenames.

After committing, wait for GitHub Pages deployment and refresh with Ctrl+Shift+R. Open check-files.html on your website to detect any missing uploads.

## Updates
Edit catalog.json to change book metadata. Upload a new book and cover alongside index.html and use their exact filenames in catalog.json. Preserve author, translator and license details. Keep a ZIP backup on your computer and another device.

## Included
31 free books; title/author/category search; language filters; PDF and text readers; page navigation; browser-local favorites, progress and bookmarks; bilingual controls; downloads and contact links.

## Limits
This static edition does not implement Google sign-in, a secure admin dashboard, payments, or cross-device account synchronization. Browser preferences stay on the current device. All published files are publicly accessible.
