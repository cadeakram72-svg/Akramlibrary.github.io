# Akram Library
Premium bilingual digital library. The original hero and Welcome remain; the lower bookstore and nature-inspired account UI are new.

## Upload
Extract this ZIP and upload every file inside akram-upload-ready to your repository root. Commit, wait for Pages deployment and hard-refresh.

## Status
35 books remain free. Dhis Naftaada and Ganacsade show $10 -> $5 offer previews, with sales closed. The two paid PDF files are excluded from this ZIP; older GitHub uploads remain public until separately removed. No payments are collected.

Account UI includes Google/email integration code, but activation requires your Supabase URL/public key and provider settings. Read ACTIVATION-GUIDE.md. Never put secrets in GitHub.

Cloud progress sync, secure paid reading, payments and admin management are still not implemented in this static edition. Browser-local favourites and reading progress continue to work.

## Latest update

## Editorial update
The Collection and all lower sections now use ivory, beige and charcoal. Five-colour backgrounds and reader palettes are removed. Sidebar provides reading-list/history, favourites, available downloads and device-local reading settings. Header links open sign-in and signup directly. Free PDF details have publication metadata, favourites, reading-list, share and related books. Authentication is still unconfigured; fill auth-config.js after completing the owner setup. No cloud sync, secure admin or payment processing is implemented.
